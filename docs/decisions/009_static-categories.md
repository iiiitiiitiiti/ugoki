# 009. 動かないパーツを部品の種類で4つの分類に分ける

- 日付: 2026-10-21
- 対象: 分類の一覧（`src/pieces/types.ts`・`src/pieces/index.ts`）と動かない部品4作の `meta.ts`

### 決定

1つだった分類「動かない部品」（id `static`）をやめ、部品の種類で次の4つに分ける。

| 分類 | id | 今入っている作 |
|---|---|---|
| 見出し | `heading` | 英字つきの見出し |
| お知らせ | `news` | お知らせ一覧 |
| 表 | `table` | 会社概要の表 |
| ナビゲーション | `navigation` | パンくずリスト |

4つとも `group: 'static'` に入れる。タブの仕組み（008）はそのまま使い、動かないパーツのタブにも分類の見出しへのリンクが並ぶ。

### 背景

ユーザー依頼「動かないページも動くパーツと同様に、パーツごとに分類分けしていきましょう」（2026-10-21）。分け方を3案で聞き、ユーザーは「部品の種類で4つ」を選んだ。

### 比較した代替案

| 案 | 却下理由 |
|---|---|
| 3分類（見出し・一覧と表・ナビゲーション） | ユーザーが4分類を選んだ。一覧と表をまとめると、今後の部品をどちらの意味で入れるか迷う |
| 「動かない部品」の1分類のまま | 動くパーツは種類ごとに分けているのにそろわない。分類が1つだと先頭のリンクも出ない |

### 影響範囲

- 分類 id `static` は無くなった。`#category-static` へのリンクは効かない
- タブの `?tab=static`（group の名前）は変わらない
- 今は各分類に1作ずつ。部品を足すときは種類の合う分類へ入れ、合わなければ分類を足す

### 検証

- 幅 375px のライト・ダークと 1280px で、動かないパーツのタブに「見出し」「お知らせ」「表」「ナビゲーション」のリンクが並ぶ。押すと各見出しへ移り、横スクロールなし（2026-10-21）
- `?tab=static#category-navigation` で開く・ハッシュを変える・戻る・再読み込みのどれでも、動かないパーツのタブで開いた（2026-10-21）
- パンくずリストの詳細ページに分類名「ナビゲーション」が出る。コンソールエラー0件（2026-10-21）
