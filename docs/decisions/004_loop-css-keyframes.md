# 004. 「ループ」の分類を足し、ロゴの帯は CSS の keyframes だけで流す

- 日付: 2026-10-21
- 対象: 15作目の題材と、新しい分類「ループ」

### 決定

操作がなくても動き続ける部品の分類「ループ」を足す。1作目は流れ続けるロゴの帯にする。同じ並びを2つ HTML に書き、帯を `@keyframes` で `translate: -50%` まで動かして繰り返す。止めるのは `animation-play-state` で、JS はボタンの切り替えだけにする。

### 背景

ユーザー依頼「案2の流れ続けるロゴの帯を作ってください」（2026-10-21）。案は `DESIGN.md` の「追加案」の2番。これまでの分類はどれも、乗せる・スクロールする・押すといった操作で動く。ロゴの帯は操作がなくても動くので、既存の分類に入らない。

### 比較した代替案

| 案 | 却下理由 |
|---|---|
| JS で並びを複製して流す | コピーした先で HTML と JS がずれると切れ目が出る。HTML に2つ書けば、コピーしたコードだけで完結する |
| `requestAnimationFrame` で毎フレーム位置を動かす | CSS のアニメーションで足りる。止める・再開するも `animation-play-state` で済み、JS の量が増えるだけになる |
| 既存の分類（ホバー）に入れる | 乗せたときの動きは「止まる」だけで、主役は乗せていない間の流れ |

### 影響範囲

- 分類は「ホバー・スクロール・画面切り替え・開閉・カルーセル・ループ」の順に並ぶ
- 5秒を超えて動き続けるので、止めるボタンを必ず付ける

### 検証

- 本番ビルドで、帯が毎秒約39px 流れることを値で確かめた。乗せている間とボタンを押した間は止まり、離す・押し直すと再開する（2026-10-21）
- 帯の半分の幅（922px）と1つ目の並びの幅（922px）が一致し、戻る瞬間に切れ目が出ない（2026-10-21）
- 幅 375px で横スクロールなし・枠の高さ 94px（上限 209px）・ダークの表示・コンソールエラー0件・`astro check` 0件（2026-10-21）
