# 008. 一覧は「動くパーツ」「動かないパーツ」のタブで切り替え、分類の見出しへのリンクを置く

- 日付: 2026-10-21
- 対象: 一覧ページ（`src/pages/index.astro`・`src/scripts/index-tabs.js`・`src/styles/pages/index.css`）

### 決定

紹介文の下にタブを2つ置き、「動くパーツ」と「動かないパーツ」を切り替える。既定は動くパーツ。分類が2つ以上あるタブには、先頭に分類の見出しへのリンクを並べる。

隠すタブは `hidden="until-found"` にし、CSS で `display: block; content-visibility: hidden` に上書きする。選んだタブは `?tab=static` として URL に残す。

### 背景

ユーザー依頼「動くパーツと動かないパーツはタブ切り替えか何かで移動できるようにしましょうか / また、アンカーリンクを設置してください」（2026-10-21）。007 で動かない部品を一覧の最後に足したため、17作を通り過ぎないと見つからなかった。

### 比較した代替案

| 案 | 却下理由 |
|---|---|
| タブを使わず、先頭のリンクで各分類へ飛ぶだけ | JS が要らず安全だが、ユーザーが挙げたタブでの切り替えにならない。動かない部品は最後に置いたままで見つけにくさが残る |
| 動かない部品を別ページに分ける | 一覧が2枚になり、カードの枠や詳細への移動の仕組みを二重に持つ。007 で同じサイトの一覧に置くと決めた |
| 隠すタブを `display: none`（ふつうの `hidden`）にする | カルーセルの横スクロールの量が 0 になり、タブを戻すと6作の自動送りが止まる。直すには各カルーセルの JS を6つ書き換える必要がある |
| タブの状態を URL のハッシュ（`#static`）に残す | 分類の見出しへのリンクもハッシュを使うので、どちらかが上書きされる |

### 影響範囲

- 分類の一覧（`categories`）に `group` を足した。新しい分類を足すときは、どちらのタブに入れるかも書く
- 動かない部品は、紹介文で「最後に置いています」から「『動かないパーツ』にまとめています」へ言い換えた
- 作品の詳細ページは変えていない

### 検証

- 幅 375px でライト・ダークとも、どちらのタブでも横スクロールなし・コンソールエラー0件（2026-10-21）
- タブは矢印キー・Home・End で移り、Tab キーで分類のリンクへ抜ける。読み上げは「部品の種類」のタブ一覧として伝わる（2026-10-21）
- `?tab=static` で開く・`#category-static` で開く・あとからハッシュを変える・詳細から戻る・再読み込みのどれでも、動かないパーツのタブで開いた（2026-10-21）
- カルーセル6作は、動かないパーツのタブへ移して戻したあとも自動送りが続く。`display: none` で隠した場合は止まることも同じ手順で確かめた（Chromium・2026-10-21）
- Safari での `content-visibility` の挙動は未確認
