# 010. 一覧に追従バーを置き、詳細ページを2カラムにする

- 日付: 2026-11-25
- 対象: 一覧（`src/pages/index.astro`・`src/scripts/index-tabs.js`・`public/index-tabs-init.js`）と詳細ページ（`src/pages/pieces/[slug].astro`）

### 決定

見た目の方向（配色・書体・点模様の枠）は変えず、使い勝手を直す。形が変わるのは次の2つ。

1. 一覧のタブと分類リンクを、画面の上端に残る1本のバーにまとめる。今いる分類のリンクは反転色で示す
2. 詳細ページは、幅 1200px 以上でデモの枠（左・576px・追従）とコード（右）を横に並べる

あわせて、戻るリンクの行き先・前後の部品へのリンク・コードの書体・導入文・カードの手がかり・共有用の画像を直した。一覧は [DESIGN.md](../DESIGN.md) の「一覧のタブと分類へのリンク」「詳細ページ」に書いた。

### 背景

ユーザー依頼「Fableの力を使ってUIやコンテンツなど改善できるところを改善してください。大幅な改善も歓迎です」（2026-11-25）。直す前に実測した問題は次のとおり。

- 幅 375px の一覧は高さ 7663px（約9画面）あり、分類リンクは先頭にしか無かった
- 詳細ページの枠は 880×660px で、1280×900 の画面ではコードが最初の画面に入らなかった
- 「一覧へ戻る」は常に先頭の「動くパーツ」へ戻った
- コードが MS ゴシックで出ていた（`pre` にだけ書体を指定し、中の `code` はブラウザ既定のまま）

### 比較した代替案

| 案 | 却下理由 |
|---|---|
| 追従するのを分類リンクだけにする | スマホの長い一覧の途中から、もう一方のタブへ移れない |
| スクロールの向きでバーを出し入れする | 表示のガクつきが出やすい。JS も増える |
| 詳細ページを1カラムのまま枠の高さだけ下げる | 一覧のカードと縦横比が変わり、ページ間の遷移で中身がはみ出す |
| 2カラムにする幅を 1024px からにする | 枠の中身が約 384px になり、幅で並びを変える作（お知らせ一覧 480px・ページ送り 420px）の広い並びが詳細ページで見られなくなる |
| カードにコピーのボタンを直接置く | 1枚に HTML・CSS・JS の3つが要り、25枚でボタンが75個になる |
| カードの出現を IntersectionObserver と時間で動かす | JS が動かないとカードが見えないままになる。CSS のスクロール連動なら未対応でも表示される |
| 開くタブを Astro が束ねたスクリプトで決める | 描画のあとに動くので、一瞬「動くパーツ」が見え、戻るときの枠の遷移が先頭の位置で始まる |

### 影響範囲

- 分類リンクの nav はパネルの外（バーの中）へ移った。選んでいないタブの nav は `hidden`
- なめらかなスクロールは CSS の `scroll-behavior` をやめ、分類リンクを押したときだけ JS で行う。読み込み時と戻ったときは一瞬で移る
- カードに `id="piece-<slug>"` が付いた。詳細ページの戻るリンクが使う
- 詳細ページの枠の余白は、幅 1200px 以上で 40px から 24px になる

### 検証

ヘッドレスの Chromium で build→preview を確かめた（2026-11-25）。

- 幅 375・768・1280px の両タブで、横スクロール 0・全25作が枠に収まる。コンソールエラー0件
- 分類リンクを押すと見出しがバーのすぐ下（15px 下）で止まり、押した分類だけが光る。スクロールすると今の分類が替わる
- `?tab=static`・`#category-table`・`?tab=static#piece-news-list`・`#piece-worm-dots` で開く・再読み込みのどれでも、正しいタブと位置で開く
- 戻るリンクで元のタブのカードへ戻る。最初の描画（pagereveal）の時点で、タブと位置が決まっている
- タブを往復したあともカルーセルの自動送りが動く（008 の回帰）
- 幅 1280px の詳細ページで、コードの先頭が最初の画面に入る。スクロールしても枠が上端から 24px に残る
- Tab キーの移動は、本文へ移動 → ロゴ → テーマ → タブ → 分類リンク → デモ → 名前 の順

未確認: Safari・Firefox の実機。ページの末尾にある最後のカードは、戻ってもバーのすぐ下までは上がらない（それ以上スクロールできないため）。
