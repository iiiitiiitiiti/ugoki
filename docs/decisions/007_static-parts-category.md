# 007. 動きを付けない部品は、同じサイトに「動かない部品」の分類を1つ足して置く

- 日付: 2026-10-21
- 対象: 分類「動かない部品」（`static`）と、その最初の4作（英字つきの見出し・お知らせ一覧・会社概要の表・パンくずリスト）

### 決定

うごき帳に分類を1つ足し、名前を「動かない部品」、id を `static` にする。並びはループの後ろ（最後）に置く。作の置き方・ファイルの分け方・コピーの仕方は、動きのある作と同じにする。

この分類の作には動きを付けない。`transition` と `animation` を書かず、`--duration` と `--ease` も置かない。リンクのホバーは色と下線だけを、時間をかけずに切り替える。

### 背景

ユーザー依頼「動きを伴わないパーツもうごきに追加していきたいです」（2026-10-21）。続けて「うごき帳に『動かない部品』の分類を1つ足す形で進めたい」と分類の形と名前が決まり、入れる部品は相談して4つに決めた。ホバーの色の変化は入れ、動きは付けないことも同じ相談で決めた。

### 比較した代替案

| 案 | 却下理由 |
|---|---|
| 動かない部品だけの別サイトを作る | 一覧・詳細・コピーの仕組みを二重に持つことになる。ユーザーは同じサイトに足す形を選んだ |
| 部品の種類ごとに分類を分ける（見出し・一覧・表・ナビ） | 4作で4分類になり、1分類1作が並ぶ。動きの分類と見分けにくい |
| 既存の分類にまぜる（パンくずのリンクをホバーへ入れるなど） | 動きの見本を探す人には、動かない作が混ざって見える |
| ホバーの色を `transition` でなめらかに変える | 分類の名前と食い違う。動きのある見本はホバーの分類が受け持つ |

### 影響範囲

- `DESIGN.md` の「動かすのは `transform`・`opacity`・`clip-path` だけ」は、この分類には当てはまらない。「動かない部品」の節にそう書いた
- サイトの紹介文と README に、動かない部品の見本もあることを足した。`--duration` と `--ease` の説明は「動きのある作」に限った
- 一覧の枠や詳細ページの仕組みは変えていない。分類の一覧に1行足しただけで、枠はほかの分類と同じに表示される

### 検証

- 幅 375px の一覧で、ライト・ダークとも4作が枠の内側に収まった。お知らせ一覧は 295×197px（枠の中身の上限は高さ約 209px）。横スクロールなし・コンソールエラー0件（2026-10-21）
- お知らせ一覧とパンくずリストは、カーソルを載せると題名の色がアクセント色に変わり、`transition-duration` は 0 秒（2026-10-21）
- 英字つきの見出しは、読み上げの見出しが「お知らせ」だけになる（2026-10-21）
- お知らせ一覧は、詳細ページの広い枠（幅 1000px の画面）で1行に並ぶ（2026-10-21）
